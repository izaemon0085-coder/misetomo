# みせとも（β版）

**商品を追う・人は追わない。** お店のアプリです。今あるスーパーやお店のレジの表（CSV）とつないで、タグシールを貼った商品の**在庫**と**防犯**をラクにします。推し活SNS「ともはね」とつながります（町の地図では、まだ「？？？？」）。

## 起動

Node.js 20 以上が必要です。外部パッケージは使っていません。

```sh
npm start        # http://localhost:3600
npm test
```

| 環境変数 | 中身 |
| --- | --- |
| `TOMOHANE_URL` | ともはねのアドレス（ふだんは `http://localhost:3000`） |
| `LINK_SECRET` | ともはね と同じ値にする合言葉。**本番では必ず設定する** |
| `MISETOMO_DATA` | 記録の置き場所（ふだんは `data/`。git に入らない） |
| `PORT` | ポート（ふだんは 3600） |

## 使い方

1. ともはねの町の地図で、右の「？？？？」を押す →「ともはねでログイン」。**はじめての人が店長**。ほかの人は店長が「スタッフ」で認める
2. **表の取りこみ**：レジや Excel の CSV（UTF-8 でも Shift_JIS でも読める）
   - 商品の一覧：見出し `JAN`・`商品名`（あれば `値段`・`発注点`）。見本は `public/samples/shohin.csv`
   - 売れたもの：見出し `JAN`・`数`。タグの付いた商品は、賞味期限の近いものから「支払いずみ」に。見本は `public/samples/uriage.csv`
   - 見出しの言い方は、`JANコード`・`商品コード`・`価格`・`売価`・`数量` なども受けつける
3. **在庫**：「シールを貼った」で、商品・枚数・賞味期限・置き場所（売り場／バックヤード）を登録。「表で書き出す」で在庫の CSV
4. **読み取り機（まね）**：本物の読み取り機がつながるまで、レジ・出口・棚卸しの「タグを読んだ」を起こせる
5. **知らせ**：支払いがまだのタグが出口を通ると、画面を開いている店員さんのスマホに知らせが出る（ふるえる）

## キャラ

| キャラ | 役目 |
| --- | --- |
| 🐹 モグ | 表の取りこみ（新しい・更新・読めなかった行） |
| 🐱 ヤマネコ | 在庫の分析：発注の目安を下まわった／賞味期限が3日以内／今月捨てた数（もったいない） |
| 🦉 フクロウ | 出口の見守り：「お客さんを決めつけず、まずはていねいに確かめてくだされ」 |
| 🐕 シバ | 店員さんへのねぎらい（棚卸しのあとなど） |

## 守ること（商品を追う・人は追わない）

- 記録するのは**商品とタグと時刻だけ**。お客さんのこと（顔・名前・姿）は記録しない。カメラは使わない
- レジを通ったタグは「支払いずみ」。それからは追わない（出口で読んでも何も残さない）
- **このお店のものではないタグ**（お客さんの持ち物など）は無視する
- 知らせは**店員さんにだけ**。言葉は「確かめてください」。「犯人」「万引き」と言わない。同じタグで何度も鳴らさない
- 知らせのあとに残すのは「支払いずみだった／商品がもどった／そのほか」だけ。**知らせの記録は30日で消える**
- 画面に「知らせが来たら」の手引き：決めつけない／ていねいに声をかける／つかまえる・問いつめるはしない（店長か警察に）／困っている様子なら市の福祉の窓口を案内
- 書き出す CSV は、表計算ソフトで式として動かないようにしてある

## 本物の読み取り機をつなぐ

店長だけに「読み取り機の合言葉」が見えます（読み取り機のまね の下）。

```sh
curl -X POST http://<お店のパソコン>:3600/api/reader \
  -H "Content-Type: application/json" \
  -H "X-Reader-Key: <合言葉>" \
  -d '{"kind":"gate","tagIds":["T0123ABCD"]}'
```

`kind` は `register`（レジ）・`gate`（出口）・`count`（棚卸し）。RFID の読み取り機・今ある防犯ゲート・バーコードのどれでも、この形で送れば使えます。ローカル回線の中で動かします。

## ともはねとのつながり

- 「ともはねでログイン」（ともじゃん・ゴーストと同じしくみ。番号はアプリごとにちがう）
- **ともはねに返すものはない**。お店の在庫やお客さんのことは、ともはねに送らない

## 正直メモ

- RFID シールは1枚 数円〜10円 → まずは、ねらわれやすくて高い商品だけ（お酒・化粧品・電池・高い肉など）
- 缶や水分の多い商品は電波で読みにくい。出口のゲートは高い → 今ある防犯ゲートとつなぐか、読み取り機1台から
- β版は1つのお店だけ。お店ごとに1台ずつ動かす
